Abstract

This paper asks whether a simple machine-learning model can help prioritize which content pages should be reviewed first using information available up to the end of March 2026. The analysis uses March 2026 performance signals and content age to rank pages, with positive movement defined as April 2026 impressions being greater than March 2026 impressions. Logistic Regression is compared with the Week-4 baseline action score using 5-fold client-grouped validation to reduce leakage between clients. Across the validation folds, Logistic Regression measured 48.0% Precision@20 and 46.8% Precision@50, compared with 36.0% and 36.4% for the Week-4 baseline. These results are observed performance on the internship dataset and support using the model as decision-support for human review, rather than as proof that recommended content changes will improve future performance.

1. Introduction / Problem Statement

Content teams often have more pages to review than they can realistically inspect at the same time. A useful ranking system can help reviewers decide which pages deserve attention first using signals that were already available at the time of the decision.

This project asks whether a simple machine-learning model can improve that prioritization compared with a transparent, rule-based baseline.

The decision point is the end of March 2026. The model therefore uses information available through March 31, including March performance signals and content age.

Research question: Can a simple machine-learning model help prioritize which content pages should be reviewed first, using information available up to the end of March 2026?

The task is framed as ranking rather than automatic optimization. The model estimates the probability of positive movement and uses that probability to prioritize pages for human review.

Positive movement is defined as April 2026 impressions being greater than March 2026 impressions.

3. Data

This analysis uses the FlyRank internship warehouse data available at the end of March 2026.

The main performance data comes from fact_content_daily_performance/**/*.parquet. Content metadata comes from dim_content.parquet.

Feature window

  • Feature window: March 1–31, 2026
  • Decision cutoff: March 31, 2026
  • Evaluation window: April 2026
  • Evaluation outcome: April impressions > March impressions

March performance and content age are used as model inputs. April impressions are used only to define the observed evaluation outcome and are not used as an input feature.

Public-safety boundary: No client names, URLs, search queries, or other private client information are exposed in this paper.

4. Methodology

Model features

  • March impressions
  • March clicks
  • March average position
  • March GA4 sessions
  • March GA4 engaged sessions
  • March CTR
  • Content age in days

Observed outcome

Positive movement is defined as:

April 2026 impressions > March 2026 impressions

This is an observed future outcome used for evaluation. It is not available to the model at the March 31 decision cutoff.

Baseline

The Week-4 baseline is a transparent action score based on March impressions and content age. It provides a simple reference point against which the learned model can be evaluated.

Model

Logistic Regression is used as a ranking model. Pages are ranked by the model's predicted probability of positive movement.

Validation

The analysis uses 5-fold GroupKFold validation grouped by client. All rows belonging to the same client remain within either the training or validation fold. This evaluates ranking performance across unseen client groups rather than randomly mixing pages from the same client.

Leakage controls

  • April outcome fields are excluded from model inputs.
  • Future product-decision fields are excluded.
  • Client names and private information are excluded.
  • URLs and private search queries are excluded.
  • The decision cutoff is March 31, 2026.

6. Limitations & Honest Framing

  • The analysis is based on one March feature window and April evaluation window.
  • Positive movement is an observed outcome, not a causal measure of whether a content change caused improvement.
  • A high model score does not guarantee positive future movement.
  • A page with a low score may still deserve review for reasons not represented in the available features.
  • Client-grouped validation improves the evaluation design, but it does not eliminate all sources of uncertainty.
  • The results should be interpreted as measured, observational, directional, decision-support evidence.
Important: The model should support human review, not automatically change content or claim to predict Google's ranking algorithm.

Recommended workflow

  1. Start with the highest-ranked pages.
  2. Inspect the page and its surrounding evidence.
  3. Use the action category as a review priority, not an automatic instruction.
  4. Make content decisions through human review.
  5. Measure subsequent performance before concluding that an intervention worked.
